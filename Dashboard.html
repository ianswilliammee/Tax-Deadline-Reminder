Annual returns and extensions

Each return gets two reminders: the original date, which is also the last day to request an extension, and the extended date if you use one.

Personal return — Form 1040

A sole proprietor or single-member LLC files Schedule C with this return, so it needs no separate entry below.

Business returns

Partnerships and S corps are due March 15 and extend to September 15. C corps follow the personal dates, April 15 to October 15.

Texas franchise tax

The extension to November only holds if the amount due is paid by May 15. Below the no-tax-due threshold there is generally nothing to file at all.
